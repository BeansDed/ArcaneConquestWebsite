# Arcane Conquest Website

A fantasy RPG-inspired front-end website built as an interactive game-style experience. The project uses custom HTML, CSS, JavaScript, animated assets, character pages, map navigation, and RPG UI elements such as health, mana, XP, quests, inventory-style cards, and dialog boxes.

## Highlights

- Game-inspired navigation and interface
- Character showcase pages
- Interactive world/map section
- Feature and developer pages
- Animated backgrounds and custom visual assets
- Vanilla JavaScript interactions with no framework required

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Project Structure

- `index.html` — main landing page
- `feature.html` / `feature.js` / `feature.css` — feature showcase
- `characters.html` / `character.js` / `character.css` — character section
- `map.html` / `map.js` / `map.css` — world map section
- `developer.html` / `developer.css` — developer page
- `styles.css` / `script.js` — shared home-page styling and behavior
- image and GIF assets — game artwork and interface elements

## Run Locally

This is a static website, so no package installation is required.

1. Clone the repository.
2. Open `index.html` in a browser.

For the best local experience, you can also serve the folder with a simple static server such as VS Code Live Server.

## Purpose

Arcane Conquest was built to experiment with turning a normal website into something that feels closer to a playable RPG interface, combining front-end development with game-inspired visual design and interaction patterns.
